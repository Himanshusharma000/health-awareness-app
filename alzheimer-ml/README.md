# 🧠 Cognitive Risk Classification Study

A reproducible machine-learning study using a **synthetically generated binary-classification dataset** to demonstrate preprocessing, PCA-based dimensionality reduction and model comparison.

> **Important:** This project is an ML/education demonstration. It is **not** a clinical Alzheimer’s diagnostic system and does not use patient medical data.

## 🎯 Objective

Compare classification approaches and show how dimensionality reduction can be integrated into a machine-learning pipeline.

## 🔬 Workflow

```text
Synthetic data generation
        ↓
Train/test split with stratification
        ↓
Standardization
        ↓
PCA retaining 90% variance
        ↓
Classification
        ↓
Accuracy / Precision / Recall / F1
        ↓
JSON result export + visual comparison
```

## 🤖 Models

- PCA + Logistic Regression
- Random Forest
- Gradient Boosting

The training script uses a fixed random seed and generates 1,600 samples with 24 features before evaluating the models on a held-out test set.

## 🧠 What This Demonstrates

- Building a reproducible classification pipeline.
- Scaling features before PCA.
- Retaining 90% variance with PCA instead of selecting an arbitrary number of components.
- Comparing a linear model against tree-based ensembles.
- Exporting machine-readable evaluation results for downstream reporting.

## 🛠️ Tech Stack

`Python` `NumPy` `Scikit-learn` `PCA` `Logistic Regression` `Random Forest` `Gradient Boosting`

## 🚀 Run Locally

```bash
cd alzheimer-ml
python -m pip install -r requirements.txt
python train.py
```

The script prints accuracy, precision, recall and F1-score and refreshes `results/model-results.json`.

# 🧠 Cognitive Risk Classification — ML Study

An educational machine-learning workflow inspired by the user's earlier Alzheimer’s-detection portfolio work. The repository uses **synthetic, non-clinical data** to demonstrate preprocessing, dimensionality reduction and model comparison.

## Pipeline
- Generate reproducible synthetic feature data
- Standardize numeric features
- Apply PCA for dimensionality reduction
- Compare Logistic Regression, Random Forest and XGBoost-compatible gradient boosting workflow
- Report accuracy, precision, recall and F1

## Run
```bash
pip install -r requirements.txt
python train.py
```

⚠️ This is a learning demonstration, not a medical diagnostic system. Synthetic performance must not be interpreted as clinical accuracy.

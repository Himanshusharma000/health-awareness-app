# 📊 Sales Analytics Engine

A reproducible Python analytics project for cleaning transaction data, calculating business KPIs, identifying category/store trends and exporting an executive summary.

## Includes
- Synthetic transaction generation for a self-contained demo
- Revenue, quantity, average order value and discount KPIs
- Category and store performance analysis
- Monthly trend aggregation
- CSV exports for downstream dashboards

## Run
```bash
pip install -r requirements.txt
python analyze.py
```

> Synthetic data is used so the project can run without proprietary customer or company information.

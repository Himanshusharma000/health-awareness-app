# 📉 Customer Churn Prediction

An end-to-end machine-learning classification project that demonstrates preprocessing, feature engineering, model comparison and evaluation on reproducible synthetic customer data.

## Pipeline
1. Generate a reproducible demo dataset
2. Split train/test data
3. Scale numeric features
4. Train Logistic Regression, Random Forest and Gradient Boosting
5. Compare accuracy, precision, recall and F1
6. Print a classification report and confusion matrix

## Tech
`Python` `Pandas` `NumPy` `Scikit-learn`

## Run
```bash
pip install -r requirements.txt
python train.py
```

> The dataset is synthetic and intended for portfolio/learning purposes. Metrics are generated when the script is run and are not presented as real-world business results.
